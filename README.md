# Cars — онлайн автокъща

Самостоятелен Next.js проект за автомобилен каталог и администриране на обяви.

## Стартиране

```bash
npm install
npm run dev
```

Отвори http://localhost:3000.

Проектът използва отделен Firebase проект `cars-d0f1d` за данните и отделен Supabase проект `cars` с public bucket `vehicles` за снимките.
